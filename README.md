# Pet Delight BD

A redesigned storefront for [petdelightbd.com](https://petdelightbd.com/), using the same modern shop language as the PetFood project in the parent folder.

## Run

```bash
cd pets-delight-website
npm install
npm run dev
```

Open [http://localhost:3100](http://localhost:3100).

Catalog prices follow the live Uttara shop (BDT). Cart and orders stay in the browser until a real checkout is connected.
